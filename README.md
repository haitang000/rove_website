# Rove website

基于 `whole_ui.png` 还原的 Rove 浏览器官网，使用 Vue 3、TypeScript、Vite、Outfit 字体和 Remix Icon。页面图片直接引用目录中提供的素材。

进站动画使用 GSAP：灰色方块扫光 → 随机方形/圆形摄影图共三轮、逐层放大 → 最后一张图片放大并完全淡出 → 网页主体放大淡入，伴随轻微鱼眼形变并恢复平面。图片淡出与网页淡入依次进行。共享缩放使图片切换时持续推进；时间轴以 1.6 倍速播放，资源就绪后的动画约 1.55 秒。资源解码完成后再播放；动画期间屏蔽滚轮、触摸及键盘滚动。系统开启减少动态效果时直接显示页面。尺寸倍率、轮次、间隔和整体速度可在 `src/components/LoadingIntro.vue` 顶部调整。

加载动画的摄影图保存在 `src/assets/intro/`，每次随机抽取六张且不重复。图片来自 Lorem Picsum / Unsplash；作者和原始链接保存在同目录的 `credits.json`。页面展示区继续使用原始设计素材。

灰色方块会持续扫光，直到全部摄影图、页面实际图片（含 SVG 标志和屏外功能卡片）、CSS 背景图及字体加载并解码完成。没有超时跳过；加载失败时保留加载画面并提供重试。抽取后的六张动画图片也在首帧前完成解码。

平滑滚动使用 Lenis 独立驱动，在进站动画结束后启用；触屏保留原生滚动。介绍段落通过 ScrollTrigger 读取滚动进度，让字母逐个从浅灰变为黑色，反向滚动时恢复。系统开启减少动态效果时使用原生滚动，并直接显示黑色文字。

页面支持简体中文和英文，按 `navigator.languages` 的偏好顺序匹配：`zh` 及其地区变体显示简体中文，`en` 及其地区变体显示英文，均不匹配时回退到英文。浏览器触发 `languagechange` 时会同步更新文案、页面标题、描述和 `html lang`。翻译集中维护在 `src/i18n.ts`，包括加载与重试提示、图片说明和无障碍标签；中文使用系统中文字体，并适配行高和逐字揭示段落的自然换行。

## 本地运行

```sh
npm install
npm run dev
```

## 构建与预览

```sh
npm run build
npm run preview
```

顶部导航栏包含 Rove 首页入口、功能区锚点、更新日志（GitHub Releases）、问答（GitHub Issues）、GitHub 和下载按钮，滚动时始终置顶显示。前 420px 滚动内，导航元素通过水平位移逐渐拉开间距，背景由透明逐渐变为白色，返回顶部时收拢并恢复透明；展开幅度根据视口限制，系统开启减少动态效果时不移动导航元素，背景透明度仍随滚动更新。窄屏将链接排到第二行，文案复用现有中英文切换逻辑。页内锚点留出导航栏高度，避免目标内容被遮挡。

首页导航栏、首屏及底部的下载按钮会先淡出首页，再淡入 `#download` 下载须知页；此地址可直接打开或刷新，支持浏览器前进、后退，返回首页时恢复原来的滚动位置。点击须知页的 Rove 标志也可返回首页。系统开启减少动态效果时直接切换页面。须知文案和页面元数据复用原有语言判断逻辑，集中维护在 `src/i18n.ts`。

下载须知页的确认按钮当前跳转至 RoveBrowser 的最新 GitHub Release，GitHub 按钮跳转至源码仓库；链接集中配置在 `src/App.vue`。没有提供安装包时，不使用虚构的下载地址。

未登录状态访问该仓库和最新 Release 返回 404，可能需要仓库访问权限。正式上线前，可在 `src/App.vue` 中将 `downloadUrl` 替换为公开安装包或发布页地址。
