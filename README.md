# Rove website

基于 `whole_ui.png` 还原的 Rove 浏览器官网，使用 Vue 3、TypeScript、Vite、Outfit 字体和 Remix Icon。页面使用 `src/assets/optimized/` 下的 WebP 素材，原始图片保留用于重新生成。

进站动画使用 GSAP：灰色方块扫光 → 随机方形/圆形摄影图共三轮、逐层放大 → 最后一张图片放大并完全淡出 → 网页主体放大淡入，伴随轻微鱼眼形变并恢复平面。图片淡出与网页淡入依次进行。共享缩放使图片切换时持续推进；时间轴以 1.6 倍速播放，资源就绪后的动画约 1.55 秒。资源解码完成后再播放；动画期间屏蔽滚轮、触摸及键盘滚动。系统开启减少动态效果时直接显示页面。尺寸倍率、轮次、间隔和整体速度可在 `src/components/LoadingIntro.vue` 顶部调整。

加载动画的原始摄影图保存在 `src/assets/intro/`，运行时使用 `src/assets/optimized/intro/` 下的压缩版本，每次随机抽取六张且不重复。图片来自 Lorem Picsum / Unsplash；作者和原始链接保存在原图目录的 `credits.json`。

灰色方块会持续扫光，直到本次抽取的六张摄影图和首屏响应式图片完成解码，再播放动画。屏外功能图、底部背景和字体不再阻塞入场；功能图及底部背景在入场结束后按需懒加载，字体以 `swap` 显示。首屏图和拉丁字体在 HTML 中预加载，移动端按视口及像素密度选择 720px 或 1440px 的首屏图。关键图片加载失败时保留重试入口；系统开启减少动态效果时立即显示页面，不请求摄影图。

截图使用无损 WebP 保留原分辨率与像素；摄影图缩至 640px 并压缩，渐变背景使用有损 WebP。需要更新素材时，安装 Python 的 Pillow 后运行 `python scripts/optimize-images.py`，生成结果需要一并提交；正常开发和构建不依赖 Python。ScrollTrigger 和 Lenis 分包，在入场结束后才请求；模块加载失败时仍可使用原生滚动和导航。

平滑滚动使用 Lenis 独立驱动，在进站动画结束后启用；触屏保留原生滚动。介绍段落通过 ScrollTrigger 读取滚动进度，让字母逐个从浅灰变为黑色，反向滚动时恢复。系统开启减少动态效果时使用原生滚动，并直接显示黑色文字。

页面支持简体中文和英文，按 `navigator.languages` 的偏好顺序匹配：`zh` 及其地区变体显示简体中文，`en` 及其地区变体显示英文，均不匹配时回退到英文。浏览器触发 `languagechange` 时会同步更新文案、页面标题、描述和 `html lang`。翻译集中维护在 `src/i18n.ts`，包括加载与重试提示、图片说明和无障碍标签；中文使用系统中文字体，并适配行高和逐字揭示段落的自然换行。

## 本地运行

```sh
npm install
npm run dev
```

## 构建与预览

```sh
npm run build
npm run preview
```

## 加载性能验证

本地生产构建使用 Chromium 冷缓存测量，下载速率 1.6 Mbps、延迟 150ms、CPU 降速 4 倍。可操作时间以入场完成、解除滚动锁定为准；资源量统计至该时刻，不包含之后懒加载的内容。以下为单次对比样本，摄影图随机选择会影响结果，并非线上 Core Web Vitals 数据。

| 场景 | 优化前可操作时间 | 优化后可操作时间 | 优化前资源量 | 优化后资源量 |
| --- | --- | --- | --- | --- |
| 桌面 1440px / 英文 | 13.98 秒 | 5.66 秒 | 2.19 MB | 0.68 MB |
| 移动端 390px / 中文 | 13.58 秒 | 5.07 秒 | 2.19 MB | 0.55 MB |
| 移动端 / 减少动态效果 | 11.85 秒 | 1.52 秒 | 2.19 MB | 0.18 MB |

入口 JavaScript 从 241.06 kB 降至 181.17 kB（构建 gzip 估算从 93.29 kB 降至 71.71 kB）。已验证六张摄影图按需请求、响应式首屏只请求一个版本、慢字体和屏外图片不阻塞入场、关键图片失败重试、滚动模块延迟及加载失败、动态偏好切换、中英文导航、下载渠道与前进后退；浏览器未出现未捕获异常。桌面首屏截图与优化前逐像素一致。

顶部导航栏包含 Rove 首页入口、功能区锚点、站内更新日志、问答（GitHub Issues）、GitHub 和下载按钮，滚动时始终置顶显示。前 420px 滚动内，导航元素通过水平位移逐渐拉开间距，背景由透明逐渐变为白色，返回顶部时收拢并恢复透明；展开幅度根据视口限制，系统开启减少动态效果时不移动导航元素，背景透明度仍随滚动更新。窄屏将链接排到第二行，文案复用现有中英文切换逻辑。页内锚点留出导航栏高度，避免目标内容被遮挡。

`#changelog` 按年月归档 `haitang000/RoveBrowser` 的 `main` 分支提交，可按功能、修复及其他类型筛选，并打开对应的 GitHub commit。进入页面后会从 GitHub 检查更新。遇到限流或网络错误时，页面会显示随网站发布的提交快照。运行 `npm run changelog:sync` 可从 GitHub 更新快照。常规构建直接使用已有快照。

首页导航栏、首屏及底部的下载按钮会先淡出首页，再淡入 `#download` 下载须知页；此地址可直接打开或刷新，支持浏览器前进、后退，返回首页时恢复原来的滚动位置。点击须知页的 Rove 标志也可返回首页。系统开启减少动态效果时直接切换页面。须知文案和页面元数据复用原有语言判断逻辑，集中维护在 `src/i18n.ts`。

下载须知页提供 Preview 和 Canary 两个版本选项，默认选中 Preview；支持鼠标、触摸及键盘方向键切换。点击下载按钮时，Preview 跳转至 RoveBrowser 的 GitHub Releases 页面，Canary 跳转至 `https://hub.haitang000.cn/haitang000/RoveBrowser/-/pipelines`；GitHub 按钮始终跳转至源码仓库。链接集中配置在 `src/App.vue`，版本说明、不稳定标记及按钮文案集中维护在 `src/i18n.ts`，随页面语言同步切换。
